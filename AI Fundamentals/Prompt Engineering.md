**_TOKENS_**
Any model, when prompted breaks the prompt into smaller pieces called _tokens_


__Determinism vs Nondeterminism__

*nondeterminism:* if you give two identical inputs to an ai model, the outputs will most likely be different.



__THE ANATOMY OF A PROMPT__

Experts break the prompt into simpler parts: the core intrusction, relavent context, desired output format, and any contraints if needed.


*zero shot prompt:* refers to the prompt given to the model without any examples.
*one shot prompt:* single example is given to clarify expectations.
*few shot prompt:* provides multiple examples
